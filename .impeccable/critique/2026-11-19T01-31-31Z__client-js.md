## 第一眼判断（A，基于截图）

遮住文字只看版式：不像驾驶舱，像"一页报告/设置页"。三张同宽同灰卡片纵向堆叠，下方 155px 空白。信息密度由"卡片高度"决定，而非"问题重要度"。

三个问题第一眼可答 **1.5 / 3**：
- 到哪了：不能——顶栏无阶段指示，阶段藏在第二张卡正文

- 下一步：能，且是全页最好的一屏

## Design Specificity

## Priority Issues

### [P0] 页内横幅缩成居中窄条（CSS 声明顺序 bug）
`.pc-banner-inline { margin:0; max-width:none }` 在 158 行，`.pc-banner { margin:12px auto 0; max-width:1120px }` 在 163 行；同权重后者覆盖前者，column flex 中 margin:auto 导致 shrink-to-fit 居中。实测：警告框 446–753（309 宽）居中，卡片 40–1160 满宽。语义从"本页数字都要打折"退化成"一条无关通知"。
修法：`.pc-banner.pc-banner-inline { margin:0; max-width:min(46em,100%); align-self:stretch }` 并移到 .pc-banner 之后。

### [P1] 降级时仍给出"你没问题"的结论和可点主 CTA
warnings 状态同屏：chip「状态待确认」+ 横幅「数字可能偏低」+ 下一步「跑提交门禁 / verdict=pass 且无待处置问题」+ 表格绿 0 + 可点「去对话发送」。把"我读不到"翻译成了"你可以提交"。
修法：model.degraded 提升为事实；degraded 时表格 blocking 渲染 `—`、CTA disabled、reason 改"结论基于不完整账本"。

### [P1] dock 的「发送」静默覆盖输入框草稿
fill/send 都是 setDraft(instruction) 再 submit；按钮文案不含"替换"含义；不可撤回。
修法：主次对调（填入输入框为主）、或 send 前检测草稿非空则先 fill、至少加一行固定提示。

### [P1] 工作区列表失败后「重试」是死按钮（B）
重试绑 refresh，refresh 依赖 selected，而失败分支从不 setSelected → 点了没反应，只能刷新整页。

### [P1] inflight 去重标志被已废弃旧请求提前清除（B）
finally 对序号判废的请求同样执行 → "已有请求在飞"跳过失效；手动刷新不去重。
