# 项目驾驶舱

在左侧栏加一个整页，只读回答三个问题：**项目到哪了、卡在哪、下一步做什么**。数据来自 trellis 任务与审核账本，不写项目里任何文件。

## 能做什么

- **下一步**：按状态机给出唯一动作和一句可直接执行的指令（有 blocking 就修、有已修待复检就复检、全绿就跑提交门禁）。
- **行动**：点「让 AI 执行下一步」跳回对话，输入框上方出现通栏，可**发送**（真的进会话）、**填入输入框**（自己改）、**忽略**。
- **阶段门**：想清楚 / 定规格 / 搭骨架 / 写代码 / 挑毛病 / 验效果 / 发出去 七道门，每道都显示推断依据。
- **任务表**：每个任务的状态、优先级、blocking 数、最近审核轮次。

## 用法

1. 安装后刷新页面，左侧栏出现「项目」图标（在 Plugins、定时任务之后）。
2. 点开是整页；顶部可切换已注册的项目工作区。
3. 每 8 秒自动刷新，也可手动点「刷新」。

## 数据来源

- `.trellis/tasks/*/task.json` — 任务状态。
- `<task>/review/history.jsonl`、`review-N.json`、`dispositions.jsonl` — 审核轮次与处置；没有 `.trellis` 时读本地账本 `.dsh/claude-review/ledger/review/`。
- `.trellis/.version`、`.trellis/spec/**` — 环境与规格文件数。

## 限制

- **只读**：不写项目文件、不改账本、不做验收自动化、不画甘特图。
- **阶段门是推断**：由证据推导并显示 `basis`，不是权威声明；`验效果`、`发出去` 两门第一版恒为待完成。
- **行动层是两步点击**：DSH 当前没有向活跃会话注入用户消息的公开 API，因此走浏览器侧的输入框填写 + 提交。
- **项目来自已注册工作区**：路由只读 `workspaceRegistry` 登记过的目录，其余一律 403。
- **只在 127.0.0.1 上服务，且插件路由不受 Web 令牌保护**：`GET /` 需要令牌，但 `GET /project-cockpit/api/panel` 不需要。它只返回已登记工作区的 trellis 元数据（任务标题、审核结论），不返回文件内容、无写操作；不要把端口暴露到局域网。
- 默认选第一个工作区，不记住上次选择；待发送指令只存在浏览器内存，刷新即丢。
- 只支持 Web profile（`engines.dsh >=0.2.2-rc.3 <0.3.0`）。
